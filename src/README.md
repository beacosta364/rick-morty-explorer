# Rick and Morty Explorer

Aplicación desarrollada con TypeScript y Vite que consume la API pública de Rick and Morty para explorar personajes de la serie.

## Características

- Listado paginado de personajes.
- Búsqueda por nombre.
- Búsqueda por ID.
- Vista detallada para búsquedas individuales.
- Manejo de estados de carga y errores.
- Diseño responsive.

## Tecnologías

- TypeScript
- Vite
- HTML5
- CSS3
- Rick and Morty API

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/beacosta364/rick-morty-explorer.git
```

Instalar dependencias:

```bash
npm install
```

Ejecutar en modo desarrollo:

```bash
npm run dev
```

Generar la versión de producción:

```bash
npm run build
```
